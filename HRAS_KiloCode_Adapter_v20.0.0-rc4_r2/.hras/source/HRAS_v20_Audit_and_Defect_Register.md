## Severity interpretation

Severity is engineering priority, not release status. A HIGH scenario may have a non-blocking disposition only when HRAS-POL-GATE-001 and the applicable QualityProfile justify it. Every BLOCKER and all conditions in HRAS-POL-NW-001 must block production/masterpiece status. Static validator PASS is structural evidence only; no runtime behavior is established.
