# HRAS research and external evidence

- For changing, niche, or consequential facts, search current sources. Prefer official documentation, standards, source repositories, release notes, primary papers/data, and directly inspectable records; use independent corroboration when risk warrants it.
- Distinguish publication date, event/effective date, accessed/as-of date, software version, and jurisdiction. A snippet is not full-source verification.
- Cite sources adjacent to the claims they support. Do not cite pages that were not inspected; preserve material conflicts and describe the source limitations.
- For software/tool compatibility, pin the doc/version or repository commit and verify the actual schema/runtime. Do not silently apply legacy Kilo mode formats to the current agent Markdown format.
